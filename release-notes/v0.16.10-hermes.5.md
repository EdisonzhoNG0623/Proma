# Proma 0.16.10-hermes.5

> Hermes Remote 实验预发布版本：让 Proma Desktop 作为远端 Hermes Agent 的安全操作前端。

## Hermes Remote

- Dashboard 与 API Server 使用独立端点和显式会话协议，不再透明 fallback 或静默降级到本地 runtime。
- 新增 per-target `EndpointManager`、单 Dashboard WebSocket Broker、断线重连、stored session resume 与 `gateway.ready` 契约。
- 附件与 prompt 收敛为同一 main-process turn：ensure session → attach → prompt ACK；失败时 Renderer 精确回滚。
- 支持图片和普通文件双向附件：输入预览、仅图片发送、历史恢复、图片大图预览、文件 Proma 内预览及系统默认程序打开。
- Dashboard 停止使用 `session.interrupt`；API Server 使用 `POST /v1/runs/{id}/stop` 并有限等待终态。
- 远端历史由 Dashboard REST canonical snapshot 重建，不再 append/dedupe 到本地 Agent JSONL。
- approval、clarify、sudo、secret 交互支持 request id、多选、自定义输入和敏感输入保护。
- Transcript 只显示 user/assistant；隐藏 system/tool、Attached Context、`@image`、`@file` 与图片专用 `[screenshot]` 展示指令。
- 项目列表与 Hermes 远端改为标准 split-pane：双区域独立滚动、拖拽/键盘调整、折叠高度恢复、Target 快速切换和可操作错误状态。

## 安全与隔离

- 新增 Electron Cookie partition、target-scoped CredentialBroker、公开 Target DTO 脱敏与原子配置存储。
- SSH 改为 `ssh2` 单连接 ownership；Dashboard/API forwards 与 SFTP 共享连接。
- 新增 SSH SHA256 host-key challenge、changed-key 阻断、POSIX/realpath containment、symlink policy 和 5 MiB UTF-8 文件读取上限。
- SFTP 只用于显式项目创建、浏览和读取；删除递归目录同步、隐藏 mkdir/bootstrap 与独立附件 IPC。
- Hermes 严格隔离 Proma 本地 Workspace、Channel、Skills、Memory、MCP、Planning、Automation 与工具上下文。
- Hermes JSON 配置使用 tmp/fsync/backup/rename；主文件和 backup 同时损坏时 fail closed。

## 长会话性能

- Agent 完成事件改为轻量元数据，同会话刷新按稳定 UUID 只读取 canonical tail。
- Renderer 展示副本会裁剪超大工具结果和 base64 图片，不修改磁盘 JSONL 真源。
- 初始消息挂载从最近 200 组降至 20 组，并支持逐批显示更早历史。
- Tool result 与 sub-agent meta 改为一次线性索引和 O(1) 查询。
- 大型过程组完成首帧立即卸载；Sticky/Minimap DOM 扫描使用 `requestAnimationFrame` 合并。

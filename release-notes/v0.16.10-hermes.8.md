# Proma 0.16.10-hermes.8

这是基于官方最新 Release `v0.16.10` 之后的未发布上游 `main@7df883bc`（Pi-only runtime）移植的 Hermes Remote 实验性 prerelease。版本号延续既有 Hermes fork 预览线，避免占用上游 `main` 清单中的未发布开发版本号。

## 本版变化

- Proma 创建和浏览的 Hermes 远端项目统一使用 `/opt/ai/projects` 根目录。
- main SFTP 创建逻辑与 Renderer 文件浏览器共用 `HERMES_REMOTE_PROJECTS_ROOT`，避免两端路径漂移。
- 新增回归测试，断言 Proma 新建远端项目时仅在 `/opt/ai/projects/<name>` 执行 realpath 与 mkdir。
- 已确认既有 `elevit` 项目位于 `/opt/ai/projects/elevit`；旧路径 `/home/ai/proma-projects/elevit` 不存在。远端审计结果为 `already_complete`，目录 owner `ai:ai`、mode `775`，未修改项目内容。
- 发布过程中上游 `main` 前进到 `7df883bc`；本版已合并新增的记忆维护、Agent 模型选择宽度以及 Tavily/Chrome MCP 代理修复。Hermes 会话继续隐藏本地 ModelSelector，普通 Pi 会话采用上游扩大的 `18rem / 42vw` 宽度。

## Hermes Remote 能力

- 保持 Proma 本地 Agent 为 Pi-only；Hermes 在主进程 service 边界作为显式 external runtime 分流。
- 支持 Hermes Dashboard 与 API Server 两种显式协议，不在协议之间或向本地 Agent 静默降级。
- 支持 Direct / SSH Tunnel、target-scoped 凭据、持久 Cookie partition、SSH host-key challenge 与受限 SFTP 文件浏览。
- 支持远端项目、远端会话、canonical REST history、实时流式输出和真实远端停止。
- 支持 approval、clarify、sudo、secret 交互卡片。
- 支持图片和普通文件的原子 turn 提交、历史媒体恢复、Proma 内预览和系统默认程序打开。
- 远端 snapshot 是历史真源；Hermes 不读取或追加本地 Agent JSONL。
- 保留侧边栏 split-pane 与超长本地 Agent 会话性能优化。

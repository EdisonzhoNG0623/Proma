# Proma 0.16.10-hermes.9

这是基于官方最新 Release `v0.16.10` 之后的未发布上游 `main@7df883bc`（Pi-only runtime）移植的 Hermes Remote 实验性 prerelease。版本号延续 Hermes fork 预览线，不占用上游 `main` 清单中的未发布开发版本号。

## 本版修复

- 恢复 Agent 输入区的独立 Runtime Selector，可在 `Pi 本地` 与已配置的 Hermes Targets 之间显式切换。
- 不恢复已经退役的 Claude Code runtime，也不恢复旧 runtime router。
- Pi → Hermes、Hermes Target A → B、Hermes → Pi 均创建并打开独立会话，不改写当前会话身份，确保 Pi JSONL 与 Hermes canonical snapshot 不会混用。
- Hermes Target 选择时显式绑定协议：配置 Dashboard 时使用 Dashboard；仅有 API Server 时使用 API Server；不做透明协议 fallback 或本地 Pi fallback。
- 无 Hermes Target 时提供“管理 Hermes 连接”入口，不静默改变 runtime。
- 本地 Pi 会话继续显示 ModelSelector；Hermes 会话仅使用远端模型配置。

## 保留能力

- Proma 创建和浏览的 Hermes 远端项目统一使用 `/opt/ai/projects`。
- 支持 Direct / SSH Tunnel、target-scoped 凭据、持久 Cookie partition、SSH host-key challenge 与受限 SFTP。
- 支持远端项目、远端会话、canonical history、实时流式、真实远端停止和交互卡片。
- 支持图片及普通文件原子 turn、历史媒体恢复、Proma 预览和系统默认程序打开。
- Proma 本地 Agent 保持 Pi-only；Hermes 继续作为显式 external runtime 在 main-process service 边界分流。

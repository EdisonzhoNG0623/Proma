# Proma 0.17.27-hermes.1

本版本将 Hermes Remote 预览线更新到 Proma 上游 `main@c52b61a5`（应用基线 `0.17.27`），并保留 Hermes 的显式 Runtime / Target 分流、远端 canonical history、附件、交互请求与远端停止能力。

## 下载

- `Proma-Setup-0.17.27-hermes.1.exe`：Windows x64 NSIS 安装版。
- `Proma-0.17.27-hermes.1-portable.zip`：Windows x64 免安装版；解压后直接运行根目录中的 `Proma.exe`。
- `SHA256SUMS.txt`：发布资产的 SHA-256 校验值。

安装版与免安装版共用 `~/.proma/` 配置与数据目录。切换版本不会迁移、复制或删除现有会话、工作区和凭据。

## 主要变化

- 合入上游 Pi-only Agent 编排、消息尾部分页、channel identity、内嵌受管浏览器和渲染性能优化。
- Hermes Dashboard 会话继续以远端 snapshot 为历史真源；Pi 会话继续使用本地 JSONL，两类历史不会互相写入。
- 保留 Dashboard / API Server、Direct / SSH Tunnel、远端项目与会话、原子附件提交、approval / clarify / sudo / secret 交互以及真实远端停止。
- Windows 发布同时提供安装包和 ZIP 免安装包；自动更新仍使用 NSIS 安装包，ZIP 仅供手动下载。
- 应用内更新、下载入口和 Release Notes 统一指向 `EdisonzhoNG0623/Proma` 的 Hermes Release；上游项目归属仍为 [`proma-ai/Proma`](https://github.com/proma-ai/Proma)。

## 注意事项

- 当前 Windows 产物未进行代码签名。首次运行时 Windows SmartScreen 可能显示“未知发布者”，请在确认下载来源及 SHA-256 后继续。
- Hermes Remote 仍为实验性功能；本地 Agent Runtime 仅使用 Pi，不包含或恢复 Claude Agent SDK。
